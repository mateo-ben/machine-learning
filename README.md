# Machine Learning: Talleres y Proyectos

Este repositorio centraliza el código, la experimentación y los recursos para las prácticas, talleres y proyectos de Machine Learning desarrollados a lo largo del curso. El enfoque abarca tanto modelos de aprendizaje supervisado (como regresión y clasificación para la predicción de variables objetivo) como aprendizaje no supervisado (como técnicas de agrupamiento para la segmentación de datos).

## Conjunto de datos utilizado

* **Nombre:** Student Performance (`student-mat.csv`)
* **Descripción:** Datos sobre el rendimiento académico de estudiantes, con más de 30 variables que incluyen hábitos de estudio, calificaciones previas y factores sociodemográficos y conductuales.
* **Fuente y Créditos:** [UCI Machine Learning Repository - Student Performance Dataset](https://archive.ics.uci.edu/dataset/320/student+performance)
